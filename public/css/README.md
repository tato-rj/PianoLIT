# Generated stylesheets

Edit `resources/sass/`, then rebuild with `npm run production`.

- `app.css` — website and web app bundle.
- `admin.css` — administration bundle.
- `shared.css` — intermediate shared layer included in both bundles.
- `vendor/` — external flag styles and their relative SVG assets.

Page templates load the appropriate main bundle. Do not edit these generated files
or add duplicate numbered copies. Include updated Mix manifest entries when shipping.
